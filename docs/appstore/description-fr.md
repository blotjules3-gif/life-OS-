## Réponses standardisées aux questions d'App Review

**Q: Do you use user data for advertising?**
R: No. LifeOS does not collect data for advertising or third-party analytics.

**Q: How can users delete their data?**
R: In-app, via Profil → Mes données → Tout effacer. Total wipe of SwiftData, UserDefaults, images, and App Group storage. See `DataDeletionSheet.swift`.

**Q: Does the app use tracking?**
R: No. `NSPrivacyTracking = false` in PrivacyInfo.xcprivacy. No tracking domains.

**Q: How is user health data handled?**
R: Read via HealthKit only. Not transmitted to any server. Used for local energy score calculation.

**Q: Does the app work offline?**
R: All modules work offline. The AI coach has a local fallback (`OfflineCoach.reply(to:ctx:)`) that responds without network. Only remote responses require internet + Mistral API.
