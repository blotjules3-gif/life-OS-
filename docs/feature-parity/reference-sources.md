## Evidence limits and required follow-through

No competitor account was purchased, no private API access was assumed, and no live banking/booking/flight provider was exercised. Public feature summaries are an initial baseline, not a complete inventory of every current premium screen. Claude must pin publisher/app ID, version, country and tier, split feature families into atomic requirements, and obtain actual behavior evidence before claiming exact parity. The four generic/unresolved identities plus Awoken platform ambiguity must remain in the ledger. Do not mark those rows complete by borrowing an unrelated app’s features.
